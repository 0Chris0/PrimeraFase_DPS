# Nombre del proyecto
Sistema de Gestión de Biblioteca "Legado Literario"

# Descripción breve de la aplicación
Sistema móvil diseñado para la gestión y consulta de libros dentro de una biblioteca. Su objetivo es facilitar a los usuarios el acceso a la información del catálogo de libros mediante una interfaz sencilla.
El sistema permite a los usuarios registrarse, iniciar sesión y visualizar los libros disponibles en la biblioteca, permitiendo una mejor organización y acceso a los recursos literarios. 

# Tecnologías utilizadas
- JavaScript
- React Native
- Expo
- Node.js (entorno de ejecución)
- Git y GitHub (control de versiones)
- Android Studio (emulador para pruebas en Android)

# Instrucciones de instalación y ejecución
1. Descargar el archivos .zip repositorio
2. Entrar a la carpeta del proyecto
3. Instalar dependencias de la aplicación:
- npm install
- npm install react-native-safe-area-context
4. Verificar el correcto funcionamiento de la app con los siguientes comandos:
- npx expo install --check Para verificar las versiones instaladas
- npx expo install --fix Para corregir las versiones si hay alguna que presente errores
5. Ejecutar la app con:
- npx expo start o npx expo start -c (para borrar el cache)
